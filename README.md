# 📈 MEE MEGA Aptos Staking Monitor (Расширение для Chrome) ## 📥 Загрузки

[![Downloads](https://img.shields.io/github/downloads/pavekscb/mee/total)](https://github.com/pavekscb/mee/releases)


Это легкое расширение для браузера Google Chrome (и Chromium-совместимых браузеров, таких как Edge, Opera, Brave), предназначенное для мониторинга вашего стейкинга токенов $MEE на платформе Aptos.

Расширение использует публичные Aptos API для получения данных о вашем балансе в стейкинге и накопленной награде в реальном времени, а также запускает симуляцию роста награды, пока вы не обновите данные вручную или автоматически.

## 🌟 Основные функции

* **Мониторинг награды:** Отображение накопленной награды ($MEE) и симуляция ее роста в секунду.
* **Мониторинг баланса:** Отображение текущего баланса $MEE в стейкинге.
* **Быстрые действия:** Кнопки для быстрого перехода к функциям **Harvest** (Забрать награду), **Stake** (Внести) и **Unstake** (Вывести) через Aptos Explorer.
* **Удобные ссылки:** Быстрый доступ к сайту Meeiro, графику $MEE, обменнику и контактам поддержки.
* **Простота установки:** Установка расширения происходит через режим разработчика Chrome.

## ⬇️ Установка расширения в Google Chrome

Поскольку это не официальное расширение, размещенное в Chrome Web Store, его установка производится через "Режим разработчика".

### Шаг 1: Скачайте и подготовьте файлы

1.  Нажмите на зеленую кнопку **`<> Code`** в этом репозитории.
2.  Выберите **`Download ZIP`** и сохраните архив на вашем компьютере.
3.  Распакуйте архив в удобную папку (например, `meeiro-chrome-extension`).

### Шаг 2: Включите режим разработчика в Chrome

1.  Откройте Google Chrome.
2.  Перейдите по адресу: `chrome://extensions/`
3.  В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).

### Шаг 3: Загрузите расширение

1.  Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
2.  Выберите папку, которую вы распаковали на Шаге 1 (`meeiro-chrome-extension`).
3.  Расширение будет успешно установлено и появится в списке.

### Шаг 4: Настройте кошелек

1.  Нажмите на значок пазла (Расширения) в правом верхнем углу браузера.
2.  Найдите **"Meeiro Aptos Staking Monitor"** и кликните по нему.
3.  Нажмите **«Сменить кошелек»** и введите свой полный Aptos-адрес, чтобы начать мониторинг ваших средств.

## 💻 Структура проекта

Проект состоит из следующих основных файлов:

| Файл | Описание |
| :--- | :--- |
| `popup.html` | Определяет структуру пользовательского интерфейса (кнопки, метки, стили). |
| `popup.js` | Содержит всю логику расширения: запросы к Aptos API, расчет наград, симуляция роста, обработка кликов и сохранение адреса кошелька. |
| `manifest.json` | Манифест расширения. Определяет имя, версию, и необходимые разрешения (`storage` и доступ к API). |
| `icon_128.png` | Иконка расширения. |
